# Вопросы по ОС
## Блок А:
1. Если представить, что компьютер - многоэтажный завод в нем ОС что-то типо ген.директора, который управляет основными структурами этого завода. 
2. Операционная система - набор программ/приложений, обеспечивающий контроль и управление аппаратной и программной частами компьютера.
ОС позволяет пользователю взаимодействовать с компьютером и понимать его, для программиста ОС также позволяет управлять необходимыми аппаратными компонентами и ПО. Еще ОС обеспечивает безопасность использования пользователем компьютера, и защищает от проникновения посторонних пользователей.
3. Если у современного ПК нет ОС, то возможности его использования сильно ограничены.
Основные варианты использования ПК без ОС:
- ПК можно включить и выключить;
- Посмотреть проверку исправности компонентов на материнской плате;
- Зайти в BIOS/UEFI;
- Изменить параметры в BIOS/UEFI(Дата/время, настройки питания, настроить некоторые параметры оперативной памяти и т.д.);
- Обновить BIOS/UEFI;
- Установить ОС с загрузочной флешки.
